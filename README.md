# 📄 PDF Merger Tool

## 📌 Description
A simple and practical Python tool that allows users to merge multiple PDF files into a single document. Built using the PyPDF2 library, this project provides an interactive command-line interface for selecting files and generating the final merged PDF.

---

## 🚀 Features
- Merge multiple PDF files into one
- Interactive command-line input
- Easy to use
- Lightweight and fast

---

## ⚙️ How to Run

### 1. Clone the repository
```bash
git clone https://github.com/Chahat-Pal/pdf-merger.git
cd pdf-merger
```

### 2. Install dependencies
pip install PyPDF2

### 3. Run the program
python main.py

### 💻 Usage Example
How many PDFs do you want to merge? 2

Enter the name of PDF 1: file1.pdf
Enter the name of PDF 2: file2.pdf

PDFs merged successfully into 'merged-pdf.pdf'
